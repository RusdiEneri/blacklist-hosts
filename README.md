# 🛡️ DNS Blocklist Registry

Koleksi daftar hitam domain (hosts/blocklist) terkurasi. Repositori ini menyediakan berbagai daftar dari HaGeZi yang siap digunakan untuk aplikasi seperti AdGuard Home, Pi-hole, NextDNS, atau uBlock Origin.

## 📖 Panduan Memilih Blocklist (Untuk Pemula)

Bingung harus pakai yang mana? Ikuti panduan singkat berikut agar tidak salah pilih:

### 1. Pilih **SATU** Level Utama (Sebagai Dasar)
Pilih salah satu dari daftar ini sesuai dengan spesifikasi router/perangkat Anda. Jangan gunakan semuanya sekaligus!
- **Light:** Sangat ringan. Hanya memblokir iklan dan pelacak dasar. Cocok untuk router tua atau HP spesifikasi rendah.
- **Multi:** **(Rekomendasi)** Kombinasi berbagai sumber. Pemblokiran seimbang, sangat cocok untuk penggunaan internet harian di rumah.
- **Pro / Pro Plus:** Lebih agresif dari Multi. Memblokir iklan, pelacak, dan malware secara lebih mendalam.
- **Ultimate:** Tingkat pemblokiran tertinggi (sangat ketat). Memblokir hampir semua yang mencurigakan. *Catatan: Terkadang bisa memblokir situs resmi, butuh whitelist manual.*

### 2. Tambahkan Kategori Khusus (Opsional)
Gabungkan dengan level utama di atas jika Anda butuh filter spesifik:
- **NSFW:** Memblokir situs dewasa/pornografi. (Sangat disarankan untuk jaringan keluarga/anak-anak).
- **Gambling:** Memblokir situs judi online.
- **Social:** Memblokir akses ke media sosial (Facebook, TikTok, Instagram, dll).
- **Popupads / Fake:** Memblokir iklan pop-up yang mengganggu dan situs penipuan.

### 3. Blokir Pelacakan Bawaan HP (Native)
Ingin HP tidak boros baterai karena diam-diam mengirim data ke pabrikan? Gunakan list ini sesuai merk HP/OS Anda:
- `native.xiaomi`, `native.samsung`, `native.oppo-realme`, `native.vivo`, `native.huawei`, `native.apple`, `native.winoffice`.

### 4. Keamanan & Anti-Bypass (Tingkat Lanjut)
- **TIF (Threat Intelligence):** Memblokir situs berbahaya, malware, dan phishing terbaru.
- **DoH / VPN-Proxy-Bypass:** Mencegah pengguna di jaringan Anda mengakali blokir DNS menggunakan VPN atau DNS-over-HTTPS.
