# 🛡️ DNS Blocklist Registry

Koleksi daftar hitam domain (hosts/blocklist) terkurasi. Repositori ini menyediakan berbagai daftar dari **HaGeZi, OISD, dan Steven Black** yang siap digunakan untuk aplikasi seperti AdGuard Home, Pi-hole, NextDNS, atau uBlock Origin.

## 📖 Panduan Memilih Blocklist

### 1. Pilih SATU Level Utama

- **Light / OISD Small:** Sangat ringan untuk penggunaan dasar.
- **Multi / OISD Big:** Kombinasi berbagai sumber untuk penggunaan umum.
- **Pro / Pro Plus:** Pemblokiran lebih agresif.
- **Ultimate:** Pemblokiran paling ketat dan mungkin membutuhkan whitelist manual.

### 2. Kategori Khusus

- **NSFW / OISD NSFW:** Memblokir situs dewasa.
- **Gambling:** Memblokir situs judi online.
- **Social:** Memblokir media sosial.
- **Popupads / Fake:** Memblokir iklan pop-up dan situs penipuan.

### 3. Native / Vendor Tracking

Daftar khusus perangkat atau platform:

- `native.xiaomi`
- `native.samsung`
- `native.oppo-realme`
- `native.vivo`
- `native.huawei`
- `native.apple`
- `native.winoffice`

### 4. Keamanan & Anti-Bypass

- **TIF:** Threat intelligence, malware, dan phishing.
- **DoH / VPN-Proxy-Bypass:** Daftar untuk membantu mengidentifikasi endpoint bypass DNS.
